# OmniCart E-commerce
1. Extract this ZIP.
2. Open the `omnicart-ecommerce` folder in VS Code.
3. In terminal run `npm install` then `npm run dev`.
4. Open the local URL shown in terminal.

React + Tailwind CSS v4 + React Router + Context API. Includes home, shop/search/filter/sort, product details, cart and localStorage. Checkout is a demo only; no real payment/backend.
